MagSafe Dark — приложение для строки меню macOS, которое управляет индикатором на разъёме MagSafe.

> Приложение использует недокументированный механизм macOS. Обновление системы или прошивки может изменить или полностью отключить эту возможность.

## Требования

- macOS 13 или новее;
- MacBook на Apple Silicon с MagSafe 3.

Проверка поддержки после установки:

```bash
magsafe-dark probe
```

Ожидаемый ответ:

```text
supported
```

## Возможности

- выключение индикатора и возврат штатного управления macOS;
- зелёный, оранжевый и мигающие режимы;
- временные режимы;
- недельное расписание;
- индикация работы, успеха и ошибки Codex CLI;
- автоматическое восстановление актуального режима после подключения питания;
- отображение батареи, зарядки и времени до завершения заряда в строке меню;
- диагностика, журналы, CLI и проверка обновлений;
- сборка установочного пакета, подпись и нотарификация.

## Установка

### Установочный пакет

```bash
zsh ./scripts/check-release.sh --package
open build
```

Локальная сборка пакета:

```bash
zsh ./build-pkg.sh
open build
```

### Установка из исходников

```bash
git clone https://github.com/bulava92/magsafe-dark.git
cd magsafe-dark
zsh ./scripts/check-release.sh
zsh ./install.sh
```

Для уже загруженного репозитория:

```bash
cd ~/Projects/magsafe-dark
git pull
zsh ./scripts/check-release.sh
zsh ./install.sh
```

Во время установки macOS один раз запросит пароль администратора. После установки обычная работа приложения и CLI не требует `sudo`.

Приложение устанавливается в `/Applications/MagSafe Dark.app`.

## Режимы индикатора

| Режим | Действие |
|---|---|
| Штатный | индикатором управляет macOS |
| Выключено | индикатор не горит |
| Зелёный | постоянный зелёный цвет |
| Оранжевый | постоянный оранжевый цвет |
| Одиночная индикация | короткая одиночная индикация |
| Медленное мигание | медленное мигание оранжевым |
| Быстрое мигание | быстрое мигание оранжевым |
| Мигание и выключение | мигание с последующим выключением |

Горячие клавиши при открытом меню:

- `⌘⇧0` — переключить «Выключено» / «Штатный режим»;
- `⌘⇧G` — зелёный;
- `⌘⇧O` — оранжевый;
- `⌘Q` — выход.

## Питание и зарядка

При подключении или отключении зарядки состояние приложения обновляется сразу. Если включено расписание, MagSafe Dark дополнительно проверяет и восстанавливает актуальный режим после стабилизации питания.

В строке меню можно отдельно включить:

- процент заряда батареи;
- признак активной зарядки;
- ожидаемое время завершения зарядки.

Эти параметры влияют только на отображение статуса и не меняют режим индикатора.

## Таймеры

Таймер временно перекрывает обычный режим индикатора. После завершения приложение заново рассчитывает актуальное состояние, а не восстанавливает устаревшее значение.

Например, если во время таймера изменилась граница расписания, после его окончания применится уже новый интервал.

## Недельное расписание

В редакторе для каждого интервала выбираются дни недели, время начала, время окончания и режим индикатора. Интервалы могут переходить через полночь.

Стандартный шаблон:

```text
Каждый день  08:00–23:00  Штатный режим
Каждый день  23:00–08:00  Выключено
```

Шаблон не работает, пока расписание не включено и не сохранено.

Вне настроенных интервалов можно использовать:

- штатный режим macOS;
- выключенный индикатор;
- последний постоянный ручной режим.

### Ручное управление при активном расписании

Ручной выбор режима при включённом расписании действует до следующей границы расписания. После неё расписание снова получает управление.

Когда расписание выключено, выбранный вручную режим сохраняется до следующего изменения пользователем.

## Codex CLI

MagSafe Dark может показывать состояния:

- работа;
- успешное завершение;
- ошибка.

Для каждого состояния выбирается отдельный режим. Для успеха и ошибки можно настроить длительность и уведомления.

Запуск через обёртку:

```bash
codex-led
codex-led exec "Fix the failing tests"
```

Если одновременно выполняется несколько задач, рабочая индикация остаётся активной до завершения последней задачи.

## Приоритеты режимов

```text
1. Пользовательский таймер
2. Активная индикация Codex
3. Ручной режим до следующей границы расписания
4. Текущий интервал расписания
5. Постоянный ручной режим
6. Штатное управление macOS
```

После завершения временного состояния приложение каждый раз пересчитывает, что должно работать сейчас. Поэтому:

- таймер не перебивается Codex;
- Codex временно перекрывает расписание;
- после Codex применяется актуальный интервал расписания;
- ручной режим при активном расписании действует только до следующей границы;
- после изменения питания восстанавливается актуальный режим.

## Значки и информация в строке меню

Строка меню может показывать текущий режим индикатора, оставшееся время таймера, процент батареи, состояние зарядки и время завершения заряда. Вид значка и состав текста настраиваются независимо от логики управления индикатором.

## CLI

Прямое управление:

```bash
magsafe-dark off
magsafe-dark system
magsafe-dark green
magsafe-dark orange
magsafe-dark flash
magsafe-dark blink-slow
magsafe-dark blink-fast
magsafe-dark blink-off
```

Таймеры:

```bash
magsafe-dark for 900 off
magsafe-dark timer-status
magsafe-dark cancel-timer
```

Расписание:

```bash
magsafe-dark schedule edit
magsafe-dark schedule status
magsafe-dark schedule enable
magsafe-dark schedule disable
magsafe-dark schedule next
```

Запуск команды с индикацией:

```bash
magsafe-dark run -- make test
magsafe-dark run --working blink-slow -- npm run build
magsafe-dark run --success green --error blink-fast -- ./deploy.sh
```

Код завершения запущенной команды сохраняется.


## Решение проблем

### Индикатор не меняется

Проверьте совместимость:

```bash
magsafe-dark probe
```

Затем откройте диагностику и журнал из меню приложения или выполните:

```bash
magsafe-dark diagnostics
magsafe-dark log-path
```

### Расписание не применяется

```bash
magsafe-dark schedule status
```

Таймер и активная индикация Codex имеют более высокий приоритет. Расписание применится после завершения временного состояния.

### Редактор расписания не открывается

```bash
magsafe-dark schedule edit
```

Запуск из Terminal покажет текст ошибки.

## Подпись и нотарификация

Репозиторий содержит скрипты для сборки, подписи и нотарификации установочного пакета. Подробные параметры находятся в документации по подписи.

## Ограничения

MagSafe Dark работает локально. Поскольку управление индикатором основано на недокументированном механизме Apple, совместимость может измениться после обновления macOS, прошивки или выхода нового поколения MacBook.

## Удаление

```bash
zsh ./uninstall.sh
```

Скрипт возвращает индикатор под штатное управление macOS и удаляет приложение, его настройки и журналы.
